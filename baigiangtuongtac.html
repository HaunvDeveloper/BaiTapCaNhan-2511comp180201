Fetch API là gì?

Fetch API là một giao diện lập trình (API) được trình duyệt cung cấp để giúp JavaScript gửi yêu cầu (request) và nhận dữ liệu (response) từ server một cách dễ dàng.

1. GET Request (Cơ bản)

Cách đơn giản nhất để lấy dữ liệu JSON từ server.

script.js
fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

2. Cú pháp Async / Await

Giúp code bất đồng bộ trở nên gọn gàng và dễ đọc như code đồng bộ.

async_example.js
async function getUser() {
  try {
    const res = await fetch('https://jsonplaceholder.../users/1');
    const user = await res.json();
    renderUser(user);
  } catch (err) {
    console.error(err);
  }
}

3. POST Request (Gửi dữ liệu)

Thêm method, headers và body để gửi dữ liệu lên server.

create_post.js
fetch('.../posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'ABC' })
})
.then(res => res.json())
.then(data => console.log(data));

4. Hiển thị Danh sách Sản phẩm

Thực tế: Lấy về 1 mảng dữ liệu và dùng vòng lặp .map() để render ra HTML.

render_products.js fakestoreapi.com 
async function getProducts() {
  // 1. Lấy dữ liệu (mảng sản phẩm)
  const res = await fetch('https://fakestoreapi.com/products?limit=4');
  const products = await res.json();

  // 2. Tạo HTML cho từng sản phẩm
  const html = products.map(p => `
    <div class="card">
      <img src="${p.image}" />
      <h3>${p.title}</h3>
      <p>$${p.price}</p>
    </div>
  `).join('');

  // 3. Hiển thị lên giao diện
  document.getElementById('grid').innerHTML = html;
}

5. Xử lý Lỗi (404/500)

Fetch API không tự bắt lỗi 404, ta phải kiểm tra response.ok.

check_error.js
fetch('.../posts/999999')
  .then(res => {
    if (!res.ok) throw new Error('Lỗi: ' + res.status);
    return res.json();
  })
  .catch(err => alert(err.message));
